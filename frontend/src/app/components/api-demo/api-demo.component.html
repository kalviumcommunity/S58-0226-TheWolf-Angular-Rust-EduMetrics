🎓 What's Happening Here?

1. HttpClient Service

Angular's HttpClient sends HTTP requests to the Rust backend at http://localhost:8080

2. Observable Pattern

All API calls return Observables. Components .subscribe() to receive data asynchronously

3. CORS Configuration

Rust backend allows requests from localhost:4200 with proper CORS headers

4. Error Handling

Failed requests are caught, logged, and displayed to the user with helpful messages

5. Type Safety

TypeScript interfaces ensure requests and responses match expected structure

6. Request Flow

Component → Service → HttpClient → Rust API → PostgreSQL → JSON Response → UI Update
